Containment Lab Timer

One page, two screens. The player screen shows the countdown and the override keypad. The game master console controls the clock, the code, and the sound. Both stay in sync when opened in the same browser.

Room setup
  1. Open this page in two windows of the same browser on the same computer (one per monitor works well).
  2. Choose Player screen in the window on the room display, tap it once to switch on sound, then use Full screen.
  3. Choose Game master console in the other window and run the game from there.
